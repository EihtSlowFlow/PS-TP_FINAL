# Guía de desarrollo para el Trabajo Final de Proyecto de Software.

1.

Introducción .

En este apartado se expondrá y estudiará tanto la tecnología utilizada, como las herramientas y metodología a utilizar en el proyecto

1.1. Introducción General 1.2. Definición del Problema 1.3. Breve Descripción de la Solución 1.4. Metodología de Desarrollo 1.5. Definición de Entorno de Ejecución (

Herramientas utilizadas

).

2.

Identificación de Necesidades

.

En esta etapa se define el problema a resolver y se fijan las normas a seguir para la dirección del proyecto. Se deben establecer los límites del proyecto, objetivos, restricciones y antecedentes. Cuanto más detallado sea este estudio, más sencilla será la realización del proyecto.

2.1. Objetivos del Sistema 2.2 Alcance del Sistema (funcionalidad a cumplir por el sistema) 2.3 Tipología de Usuarios (tipos de usuarios y roles) 2.4 Organización y Funciones de los usuarios (

organización de los usuarios del sistema, podrían utilizar una tabla para la definición de que hace cada usuario.

)

3.

Análisis De Requisitos

.

El objetivo de esta fase o etapa es alcanzar un conocimiento suficiente del sistema, definiendo las necesidades, problemas y requisitos del cliente, para expresarlo mediante los modelos de procesos y de datos.

3.1. Identificación y Detalle de las Historias de Usuarios o Casos de Usos. 3.2 Diagrama de Clases 3.3. Modelo de Datos. 3.3.1. Diagrama Entidad - Relación 3.3.2. Modelo relacional (

definición de las tablas, columnas, Fk, etc

)

4.

Estudio de la Arquitectura

.

El objetivo de esta fase es definir las posibles soluciones de arquitectura que satisfagan tanto los requisitos del cliente como las restricciones de diseño.

4.1. Arquitectura Escogida 4.1.1 Framework de desarrollo. 4.1.2 Tecnologías utilizadas. 4.1.3 Características de la arquitectura Web elegida (

Separación de capas, etc

). 4.1.4 Definición y Características del patrón MVC.

4.2. Diagrama de presentación/componentes (

gráfico de componentes de software

) 4.3. Requisitos de Hardware y Software
